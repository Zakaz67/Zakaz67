# Глава 4. Создание числовых списков

## Зачем нужны числовые списки

Списки подходят не только для хранения слов. В них можно хранить наборы чисел: например, результаты игр, температуру, координаты или другие данные.

Python предоставляет инструменты, которые помогают создавать и обрабатывать такие списки.

## Функция `range()`

Функция `range()` создаёт последовательность чисел.

```python
for value in range(1, 5):
    print(value)
```

**Результат:**

```text
1
2
3
4
```

Важно: правая граница не включается. Поэтому `range(1, 5)` даёт числа от 1 до 4, а не до 5.

Чтобы получить числа от 1 до 5 включительно, укажи правую границу на единицу больше:

```python
for value in range(1, 6):
    print(value)
```

**Запомни:** если нужно включить последнее число, обычно указывай в `range()` число на единицу больше.

## Создание списка с помощью `list()`

Сам по себе `range()` задаёт последовательность чисел. Чтобы получить из неё именно список, используй функцию `list()`:

```python
numbers = list(range(1, 6))
print(numbers)
```

**Результат:**

```text
[1, 2, 3, 4, 5]
```

Разберём запись:
- `range(1, 6)` задаёт числа от 1 до 5.
- `list(...)` превращает эту последовательность в список.
- `numbers` — переменная, в которой хранится получившийся список.

## Третий аргумент `range()`: шаг

У `range()` можно указать три аргумента:

```python
range(начало, конец, шаг)
```

Третий аргумент задаёт, на сколько увеличивается число при каждом следующем шаге.

Например, список чётных чисел от 2 до 10:

```python
even_numbers = list(range(2, 11, 2))
print(even_numbers)
```

**Результат:**

```text
[2, 4, 6, 8, 10]
```

Здесь:
- `2` — первое число;
- `11` — правая граница, которая не включается;
- `2` — шаг: каждый раз прибавляется 2.

Ещё пример:

```python
numbers = list(range(1, 11, 3))
print(numbers)
```

Результат: `[1, 4, 7, 10]`. Каждое следующее число на 3 больше предыдущего.

## Создание списка с помощью цикла `for` и `append()`

Можно не только получать готовую последовательность через `range()`, но и постепенно собирать новый список.

Например, создадим список квадратов чисел от 1 до 10.

Квадрат числа — это число, умноженное само на себя. В Python возведение в степень записывается с помощью двух звёздочек: `**`.

```python
squares = []

for value in range(1, 11):
    square = value ** 2
    squares.append(square)

print(squares)
```

**Результат:**

```text
[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
```

Разберём по шагам:
1. `squares = []` — создаём пустой список, в который будем складывать результаты.
2. `for value in range(1, 11):` — перебираем числа от 1 до 10.
3. `square = value ** 2` — возводим текущее число в квадрат и сохраняем результат во временную переменную `square`.
4. `squares.append(square)` — добавляем получившийся квадрат в конец списка.
5. `print(squares)` — после завершения цикла выводим весь список.

Можно сделать то же самое короче, без временной переменной:

```python
squares = []

for value in range(1, 11):
    squares.append(value ** 2)

print(squares)
```

Оба варианта дают одинаковый результат. Первый иногда легче читать, потому что каждый шаг записан отдельно. Второй короче.

## Простая статистика: `min()`, `max()` и `sum()`

В Python есть встроенные функции для работы с числовыми списками.

```python
digits = [1, 2, 3, 4, 5, 6, 7, 8, 9, 0]

print(min(digits))
print(max(digits))
print(sum(digits))
```

**Результат:**

```text
0
9
45
```

Что делает каждая функция:

| Функция | Назначение |
|---|---|
| `min(список)` | Находит наименьшее значение |
| `max(список)` | Находит наибольшее значение |
| `sum(список)` | Складывает все значения |

Эти функции подходят и для очень больших числовых списков.

## Генераторы списков (list comprehension)

Генератор списка позволяет создать новый список в одной строке. Он объединяет цикл `for` и добавление элементов в список.

Вот пример, который создаёт список квадратов от 1 до 10:

```python
squares = [value ** 2 for value in range(1, 11)]
print(squares)
```

**Результат:**

```text
[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
```

Как читать эту запись:
- `value ** 2` — выражение, которое вычисляется для каждого числа;
- `for value in range(1, 11)` — цикл, который передаёт в выражение числа от 1 до 10;
- квадратные скобки `[ ]` показывают, что создаётся список.

Обрати внимание: в этой короткой записи после `for` не ставится двоеточие. Это не обычный блок цикла, а специальный синтаксис генератора списка.

Генератор списка и обычный цикл могут дать один и тот же результат. Пока достаточно научиться узнавать такую запись в чужом коде. Продолжай использовать обычный цикл, если он понятнее.

## Главное из раздела

- `range(start, stop)` задаёт последовательность от `start` до числа перед `stop`.
- Правая граница `range()` не включается.
- `list(range(...))` превращает числовую последовательность в список.
- Третий аргумент `range(start, stop, step)` задаёт шаг.
- `** 2` возводит число в квадрат.
- `append()` добавляет элемент в конец списка.
- `min()`, `max()` и `sum()` находят минимум, максимум и сумму числового списка.
- Генератор списка позволяет создать список в одной строке, совместив выражение и цикл `for`.
