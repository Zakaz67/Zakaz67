## 1. Перебор списка с помощью цикла `for`

Цикл `for` позволяет последовательно обработать каждый элемент списка.

```python
magicians = ['alice', 'david', 'carolina']

for magician in magicians:
    print(magician)
```

- `for` начинает цикл.
- `magician` — переменная, которая на каждой итерации получает очередной элемент.
- `in` связывает переменную с последовательностью, которую нужно перебрать.
- Двоеточие `:` завершает заголовок цикла.
- Тело цикла выделяется отступом в четыре пробела.
- После завершения цикла программа продолжает выполнение со следующей строки без отступа.

Имя переменной цикла выбирают понятным и связанным с элементами последовательности.

## 2. Работа с числовыми последовательностями: `range()`

Функция `range()` задаёт последовательность чисел.

```python
for value in range(1, 5):
    print(value)
```

Результат — числа от 1 до 4. Правая граница не включается.

Чтобы получить числа от 1 до 5 включительно, укажи правую границу на единицу больше:

```python
for value in range(1, 6):
    print(value)
```

У `range()` можно указать шаг:

```python
for value in range(2, 11, 2):
    print(value)
```

Здесь будут получены чётные числа от 2 до 10.

Общая форма:

```python
range(start, stop, step)
```

- `start` — начало последовательности;
- `stop` — исключённая правая граница;
- `step` — шаг между числами.

## 3. Преобразование последовательности в список

Функция `range()` задаёт последовательность, а `list()` позволяет получить из неё список.

```python
numbers = list(range(1, 6))
print(numbers)
```

Результат:

```text
[1, 2, 3, 4, 5]
```

## 4. Числовые списки и вычисления

Можно постепенно наполнять список результатами вычислений с помощью `append()`.

```python
squares = []

for value in range(1, 11):
    squares.append(value ** 2)

print(squares)
```

- `squares = []` создаёт пустой список.
- `value ** 2` возводит число в квадрат.
- `append()` добавляет вычисленное значение в конец списка.

Для анализа числового списка есть встроенные функции:

| Функция | Назначение |
|---|---|
| `min(numbers)` | Наименьшее значение |
| `max(numbers)` | Наибольшее значение |
| `sum(numbers)` | Сумма значений |

## 5. Генераторы списков (list comprehension)

Генератор списка позволяет создать список в одной строке, объединив выражение и цикл `for`.

```python
squares = [value ** 2 for value in range(1, 11)]
```

Внутри квадратных скобок сначала записано выражение для нового элемента, затем цикл, который предоставляет значения. В этой конструкции после `for` не ставится двоеточие.

Обычный цикл с `append()` и генератор списка могут создавать одинаковые результаты. На начальном этапе важно уметь читать обе формы и выбирать понятную.

## 6. Срезы списка

Срез позволяет получить часть списка.

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

print(players[0:3])
print(players[1:4])
print(players[-3:])
```

Форма среза:

```python
list_name[start:stop]
```

- Начальный индекс включается.
- Конечный индекс не включается.
- Если начало не указано, срез начинается с первого элемента.
- Если конец не указан, срез продолжается до конца списка.
- Отрицательные индексы позволяют обращаться к элементам с конца.

Например, `players[:3]` возвращает первые три элемента, а `players[-3:]` — последние три.

## 7. Копирование списков

Чтобы создать независимую копию всего списка, можно использовать полный срез:

```python
my_foods = ['pizza', 'falafel', 'carrot cake']
friend_foods = my_foods[:]
```

Теперь это два отдельных списка. Изменения одного списка не добавляют элементы автоматически в другой.

Важно отличать копирование от обычного присваивания:

```python
friend_foods = my_foods
```

В этом случае обе переменные указывают на один и тот же список. Это не независимая копия.

## 8. Кортежи (tuple)

Кортеж — последовательность элементов, которую нельзя изменять по отдельности после создания.

```python
dimensions = (200, 50)

for dimension in dimensions:
    print(dimension)
```

Кортеж обычно записывается с круглыми скобками.

Попытка изменить элемент:

```python
dimensions[0] = 400
```

приведёт к ошибке `TypeError`, потому что элементы кортежа неизменяемы.

Но переменной можно присвоить новый кортеж:

```python
dimensions = (400, 100)
```

Это не изменение прежнего кортежа, а присваивание переменной нового объекта.

## 9. Стиль оформления кода: PEP 8

PEP 8 — руководство по стилю кода Python. Его рекомендации делают программы единообразными и более удобными для чтения.

Основные правила, разобранные в упражнениях:

- Использовать четыре пробела для каждого уровня отступа.
- Стараться, чтобы строки кода были короче 80 символов; в PEP 8 для обычного кода указан предел 79 символов.
- Не злоупотреблять пустыми строками: они должны разделять логические части, а не появляться случайно.
- Давать переменным понятные имена. Для обычных имён переменных используют стиль `snake_case`, например `friend_foods`.
- Ставить пробелы вокруг операторов и после запятых там, где этого требует обычное оформление Python.

Клавиша Tab — клавиша табуляции. Редактор можно настроить так, чтобы нажатие Tab вставляло четыре пробела. В VS Code для этого используется режим `Indent Using Spaces` с размером `4`.

В упражнении 4-15 также предлагалось включить вертикальную направляющую на позиции 80-го символа. Это визуальная подсказка редактора, а не часть синтаксиса Python.
