# Глава 3. Списки

## Добавление элементов в список

Python позволяет добавлять новые элементы в уже существующие списки.

### Метод `append()`

Метод `append()` добавляет новый элемент **в конец списка**.

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

motorcycles.append('ducati')

print(motorcycles)
```

**Результат:**

```python
['honda', 'yamaha', 'suzuki', 'ducati']
```

Также можно начать с пустого списка и постепенно заполнять его с помощью `append()`:

```python
motorcycles = []

motorcycles.append('honda')
motorcycles.append('yamaha')
motorcycles.append('suzuki')

print(motorcycles)
```

**Когда полезно:** когда заранее неизвестно, какие элементы появятся в программе. Можно добавлять их по мере получения.

### Метод `insert()`

Метод `insert()` вставляет новый элемент **в указанную позицию списка**.

У метода два аргумента:
- `index` — индекс позиции, куда нужно вставить элемент;
- `value` — значение нового элемента.

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

motorcycles.insert(0, 'ducati')

print(motorcycles)
```

**Результат:**

```python
['ducati', 'honda', 'yamaha', 'suzuki']
```

В примере индекс `0` означает начало списка. Новый элемент занимает эту позицию, а остальные элементы сдвигаются вправо.

## Удаление элементов из списка

### Метод `pop()` — удаление элемента с возвратом значения

Метод `pop()` удаляет элемент из списка и **возвращает его значение**. Если индекс не указан, удаляется последний элемент.

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

popped_motorcycle = motorcycles.pop()

print(motorcycles)
print(popped_motorcycle)
```

**Результат:**

```python
['honda', 'yamaha']
suzuki
```

В этом примере `pop()` удалил последний элемент — `'suzuki'`. При этом его значение сохранилось в переменной `popped_motorcycle`, поэтому его всё ещё можно использовать.

### Удаление элемента по индексу

В `pop()` можно передать индекс элемента, который нужно удалить:

```python
motorcycles = ['honda', 'yamaha', 'suzuki']

first_motorcycle = motorcycles.pop(0)

print(motorcycles)
print(first_motorcycle)
```

**Результат:**

```python
['yamaha', 'suzuki']
honda
```

Здесь удаляется элемент с индексом `0` — первый элемент списка. Его значение возвращается и сохраняется в переменной.

**Когда полезно:** `pop()` подходит, когда элемент нужно убрать из списка, но при этом сохранить его значение и использовать дальше.

### Кратко

| Метод | Что делает |
|---|---|
| `append(value)` | Добавляет элемент в конец списка |
| `insert(index, value)` | Вставляет элемент в указанную позицию |
| `pop()` | Удаляет и возвращает последний элемент |
| `pop(index)` | Удаляет и возвращает элемент по индексу |
