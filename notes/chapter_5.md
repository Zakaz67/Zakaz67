## 1. Условие \`if\`

\`if\` выполняет блок кода, когда условие истинно (\`True\`).

\`\`\`python
age = 18

if age >= 18:
    print("Доступ разрешён")
\`\`\`

Тело условия выделяется отступом. После условия ставится двоеточие.

## 2. Операторы сравнения

| Оператор | Значение |
|---|---|
| \`==\` | равно |
| \`!=\` | не равно |
| \`>\` | больше |
| \`<\` | меньше |
| \`>=\` | больше или равно |
| \`<=\` | меньше или равно |

Не путать \`=\` (присваивание) и \`==\` (сравнение).

## 3. Объединение условий и проверка принадлежности

- \`and\` — оба условия должны быть истинными.
- \`or\` — достаточно одного истинного условия.
- \`in\` — проверяет, содержится ли элемент в последовательности.
- \`not in\` — проверяет, что элемента в последовательности нет.

Пример:

\`\`\`python
users = ["admin", "lina", "marci"]

if "admin" in users:
    print("Пользователь найден")
\`\`\`

## 4. Цепочка \`if-elif-else\`

Используется, когда нужно выбрать один вариант из нескольких.

\`\`\`python
number = 2

if number == 1:
    print("Первый")
elif number == 2:
    print("Второй")
else:
    print("Другой вариант")
\`\`\`

Python проверяет условия сверху вниз. Выполняется первый блок, условие которого истинно. \`else\` срабатывает, если предыдущие условия не подошли.

## 5. Проверка пустого списка

Список можно непосредственно использовать в условии:

\`\`\`python
requested_toppings = []

if requested_toppings:
    print("Список не пуст")
else:
    print("Список пуст")
\`\`\`

Пустой список оценивается как \`False\`, непустой — как \`True\`.

## 6. Проверка строк без учёта регистра

Строки сравниваются с учётом регистра: \`"Lina"\` и \`"lina"\` — разные строки.

Метод \`.lower()\` возвращает строку в нижнем регистре:

\`\`\`python
username = "Lina"
print(username.lower())
\`\`\`

Важно: \`.lower()\` — метод строки, а не списка. Чтобы сравнивать имена без учёта регистра, нужно привести к одному регистру обе сравниваемые строки.

## 7. Вложенные циклы \`for\`

Один цикл можно поместить внутрь другого. Внутренний цикл выполняется для каждого прохода внешнего цикла.

\`\`\`python
first_list = [1, 2]
second_list = ["a", "b"]

for number in first_list:
    for letter in second_list:
        print(number, letter)
\`\`\`

В задаче на сравнение двух списков это позволяет сравнить очередной элемент первого списка с элементами второго списка.

## 9. Стиль оформления условий

При оформлении кода важно:

- использовать четыре пробела на уровень отступа;
- ставить пробелы вокруг операторов сравнения;
- ставить двоеточие после \`if\`, \`elif\` и \`else\`;
- выравнивать блоки по правильным уровням отступов;
