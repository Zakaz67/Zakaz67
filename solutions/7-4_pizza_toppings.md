## Итоговый вариант после разбора

```python
while True:
    sa = input("Что хочешь добавить в заказ: ")

    if sa == "quit":
        break

    print("Ваша начинка добавлена в меню")
```

## Объяснение кода

1. `while True:` запускает цикл, который будет повторяться, пока его явно не остановить.
2. `sa = input(...)` запрашивает у пользователя название начинки и сохраняет ввод в переменную `sa`.
3. `if sa == "quit":` проверяет, ввёл ли пользователь команду завершения.
4. `break` немедленно завершает цикл, если пользователь ввёл `quit`.
5. `print(...)` выводит подтверждение добавления начинки, если введено не `quit`.

Проверка команды `quit` стоит до сообщения о добавлении, поэтому сама команда выхода не считается начинкой.
