## Мой код

```python
names = ["yamaha", "honda", "alpha"]
print("я бы хотет " + names[0])
print("я бы хотет " + names[1])
print("я бы хотет " + names[2])
```

## Объяснение кода

1. `names` — список из трёх строк с названиями.
2. `names[0]`, `names[1]` и `names[2]` обращаются к каждому элементу списка.
3. Оператор `+` соединяет текст утверждения с названием из списка.
4. Каждый вызов `print()` выводит отдельное утверждение.

## Примечание

Логика Python правильная. В тексте сообщения есть опечатка: «хотет» вместо «хотел». Она не мешает выполнению программы, но влияет на текст вывода.
