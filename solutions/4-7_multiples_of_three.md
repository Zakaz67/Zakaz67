# 4-7 — Тройки

## Исходный код

```python
numbers = range(3, 31)
for a in numbers:
    if a % 3 == 0:
        print(a)
```

## Объяснение

- `numbers = range(3, 31)` — задаёт последовательность целых чисел от 3 до 30 включительно. Число 31 не входит в диапазон.
- `for a in numbers:` — цикл по очереди перебирает все числа этой последовательности.
- `if a % 3 == 0:` — оператор `%` находит остаток от деления. Условие проверяет, делится ли текущее число на 3 без остатка.
- `print(a)` — выполняется только тогда, когда условие истинно, и выводит число, кратное 3.

## Проверка

**Результат правильный:** выводятся 3, 6, 9, 12, 15, 18, 21, 24, 27 и 30.

**Нюанс условия:** задание просит создать список именно чисел, кратных 3. В этом коде перебирается весь диапазон, а подходящие числа отбираются условием `if`; отдельный список кратных чисел не создаётся. Поэтому результат верный, но структура решения не полностью совпадает с формулировкой. Исходный код оставлен без изменений.
