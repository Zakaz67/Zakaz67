# 5-1 — Условные проверки

## Условие

Точная формулировка упражнения для этого файла не найдена в репозитории или доступных сообщениях. Поэтому ниже разобран фактический код без предположений о дополнительных требованиях.

## Исходный код

```python
car = 'subaru'
print("Is car == 'subaru'? I predict True.")
print(car == 'subaru')
print("\nIs car == 'audi'? I predict False.")
print(car == 'audi')
```

## Объяснение

- `car = 'subaru'` — создаёт переменную `car` и сохраняет в ней строку `'subaru'`.
- `print("Is car == 'subaru'? I predict True.")` — выводит текст с прогнозом результата первой проверки.
- `print(car == 'subaru')` — оператор `==` сравнивает значение переменной `car` со строкой `'subaru'`. Они одинаковые, поэтому выражение возвращает булево значение `True`.
- `print("\nIs car == 'audi'? I predict False.")` — сначала выводит символ новой строки `\n`, а затем текст с прогнозом результата второй проверки.
- `print(car == 'audi')` — сравнивает значение `car` со строкой `'audi'`. Строки различаются, поэтому результат — `False`.

## Результат

```text
Is car == 'subaru'? I predict True.
True

Is car == 'audi'? I predict False.
False
```

## Проверка

**Обе проверки работают правильно:** первая возвращает `True`, вторая — `False`. Оба прогноза в сообщениях совпадают с фактическими результатами.
