# 4-15 — Анализ кода

## Что требовалось

Выбрать три программы из главы 4 и проверить их оформление по рекомендациям PEP 8:
- четыре пробела на каждый уровень отступа;
- строки короче 80 символов;
- разумное использование пустых строк.

## Программа 1 — Dimensions

### Код

```python
dimensions = (200, 50)
print("Original dimensions:")

for dimension in dimensions:
    print(dimension)

dimensions = (400, 100)
print("\nModified dimensions:")

for dimension in dimensions:
    print(dimension)
```

### Разбор

- Отступ внутри цикла составляет четыре пробела.
- Строки короткие и не приближаются к ограничению в 80 символов.
- Пустые строки отделяют вывод исходных и изменённых размеров.

**Оценка:** по проверенным в упражнении требованиям оформление соответствует заданию.

## Программа 2 — My foods

### Код

```python
my_foods = ['pizza', 'falafel', 'carrot cake']

# This doesn't work:
friend_foods = my_foods

my_foods.append('cannoli')
friend_foods.append('ice cream')

print("My favorite foods are:")
print(my_foods)

print("\nMy friend's favorite foods are:")
print(friend_foods)
```

### Разбор

- Отступов внутри блоков нет, поэтому требование о четырёх пробелах здесь не затрагивается.
- Строки короче 80 символов.
- Пустая строка после создания списка отделяет его от дальнейших операций; остальные строки сгруппированы компактно.
- Комментарий отделён от кода и объясняет следующий участок.

**Оценка:** по проверенным в упражнении требованиям оформление соответствует заданию.

Отдельно о логике программы: `friend_foods = my_foods` не создаёт копию списка. Обе переменные указывают на один и тот же список. Это вопрос поведения Python, а не нарушение PEP 8.

## Программа 3 — Players

### Код

```python
players = ['charles', 'martina', 'michael', 'florence', 'eli']

print("Here are the first three players on my team:")

for player in players[:3]:
    print(player.title())
```

### Разбор

- Внутри цикла используется отступ в четыре пробела.
- Строки короче 80 символов.
- Пустая строка отделяет список игроков от вывода, а заголовок — от цикла.

**Оценка:** по проверенным в упражнении требованиям оформление соответствует заданию.

Все три выбранные программы аккуратно оформлены по трём основным критериям упражнения. Код был прислан для проверки в чате; отдельная автоматическая проверка длины строк и настроек редактора не выполнялась.
