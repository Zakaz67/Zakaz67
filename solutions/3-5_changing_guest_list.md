# 3-5 — Изменение списка гостей

**Книга:** «Изучаем Python», Эрик Мэтиз  
**Глава:** 3  
**Упражнение:** 3-5

## Мой код

```python
name = ["DIMA", "YAGODOTA", "LIZA SSK"]
print(name[0] + " тебя на ужин хочу пригласить")
print(name[1] + " тебя на ужин хочу пригласить")
print(name[2] + " тебя на ужин хочу пригласить")
del name[0]
print(name[0])
name.insert(0, "sanya")
print(name)
```

## Объяснение кода

1. `name = [...]` создаёт список из трёх имён.
2. Первые три вызова `print()` по очереди выводят приглашения для элементов с индексами `0`, `1` и `2`.
3. `del name[0]` удаляет первый элемент списка. После удаления индексы оставшихся элементов сдвигаются.
4. `print(name[0])` выводит новый первый элемент списка — тот, который раньше находился на позиции с индексом `1`.
5. `name.insert(0, "sanya")` вставляет строку `"sanya"` в начало списка, на позицию с индексом `0`.
6. Последний `print(name)` выводит весь список после изменения.

## Статус

Код создаёт список, выводит первоначальные приглашения, удаляет первого гостя, показывает нового первого гостя и вставляет имя `sanya` в начало списка.

Если это упражнение 3-5 «Изменение списка гостей», то изменение списка показано, но повторные приглашения после изменения списка в коде не выводятся.
