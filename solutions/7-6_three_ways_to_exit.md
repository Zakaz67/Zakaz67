# 7-6 — Три способа выхода из цикла

**Книга:** «Изучаем Python», Эрик Мэтиз  
**Глава:** 7  
**Упражнение:** 7-6 «Три выхода»

## Мой код

```python
active = True
while active:
    a = input(";")

    if a == "quit":
        active = False
        break

    print("bruh")
```

## Объяснение кода

1. `active = True` — создаёт переменную-флаг. Значение `True` означает, что цикл должен работать.
2. `while active:` — цикл повторяется, пока переменная `active` имеет значение `True`.
3. `a = input(";")` — программа получает ввод пользователя и сохраняет его в переменную `a`.
4. `if a == "quit":` — проверяет, ввёл ли пользователь команду выхода.
5. `active = False` — меняет значение флага на `False`. При следующей проверке условие `while active` стало бы ложным.
6. `break` — немедленно прерывает цикл, не дожидаясь следующей проверки условия `while`.
7. `print("bruh")` — выполняется, если пользователь ввёл не `quit`.

## Статус упражнения

В коде присутствуют `while active` и `break`, но два способа завершения пока не продемонстрированы независимо: при вводе `quit` сначала меняется `active`, а затем сразу срабатывает `break`. Поэтому цикл фактически завершается командой `break`, а не повторной проверкой `while active`.
