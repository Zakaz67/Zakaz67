## Мой код

```python
names = ["parya", "pdidi", "pachik"]
print("пупс" + names[0])
print("пупс" + names[1])
print("пупс" + names[2])
```

## Объяснение кода

1. `names` хранит три строки с именами.
2. В каждом вызове `print()` оператор `+` соединяет строку `"пупс"` с одним из элементов списка.
3. Индексы `0`, `1` и `2` позволяют обратиться к каждому имени отдельно.
4. В результате выводятся три персонализированных сообщения.

## Примечание

Код работает. Между словом `пупс` и именем нет пробела, поэтому в выводе они будут слиты. Это особенность оформления сообщения, а не ошибка Python.

## Статус

Задание выполнено: для каждого элемента списка выведено отдельное сообщение.
