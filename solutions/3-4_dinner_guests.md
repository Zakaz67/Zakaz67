## Мой код

```python
name = ["DIMA", "YAGODOTA", "LIZA SSK"]
print(name[0] + " тебя на ужин хочу пригласить")
print(name[1] + " тебя на ужин хочу пригласить")
print(name[2] + " тебя на ужин хочу пригласить")
```

## Объяснение кода

1. `name = [...]` создаёт список из трёх строк — имён приглашённых.
2. `name[0]` обращается к первому гостю, `name[1]` — ко второму, а `name[2]` — к третьему.
3. В каждом вызове `print()` оператор `+` соединяет имя гостя с текстом приглашения.
4. Каждый вызов `print()` выводит отдельное приглашение.

## Статус

Задание выполнено: создан список из трёх гостей и выведено отдельное приглашение каждому.
