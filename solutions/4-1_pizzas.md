## Мой код

```python
pizza = ["margarite", "peperoni", "chiken burger"]
for pizzas in pizza:
    print("i like "  + pizzas)
print("i really like pizza")
```

## Объяснение кода

1. `pizza = [...]` создаёт список из трёх строк с названиями любимой пиццы.
2. `for pizzas in pizza:` запускает цикл. На каждом повторении переменная `pizzas` получает очередной элемент списка `pizza`.
3. `print("i like " + pizzas)` соединяет текст `"i like "` с названием текущей пиццы и выводит получившееся сообщение.
4. Когда цикл заканчивается, выполняется `print("i really like pizza")`. Эта строка находится после цикла, поэтому выводится один раз.

## Примечание

Цикл и вывод сообщений работают. В названиях есть опечатки: обычно пишут `margherita`, `pepperoni` и `chicken`. В примере из задания после названия также добавлено слово `pizza`, например: `I like pepperoni pizza`.
