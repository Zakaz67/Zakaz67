# 4-13 — Буфет

## Исходный код

```python
menu = ("nasvay", "solunka", "neskwik", "pivo", "pizza")

print("вот меню сук")
for menus in menu:
    print(menus)

#menu[0] = 250
#print(menu)

menu = ("jaime", "solunka", "neskwik", "onion", "pizza")
print("вот меню сук")
for menus in menu:
    print(menus)
```

## Объяснение

- `menu = (...)` создаёт кортеж из пяти элементов. Кортеж похож на список, но его элементы нельзя изменять по отдельности.
- Первый `print()` выводит заголовок перед списком блюд.
- Цикл `for menus in menu` перебирает кортеж: на каждой итерации переменная `menus` получает очередной элемент.
- `print(menus)` выводит текущий элемент кортежа.
- Строки `#menu[0] = 250` и `#print(menu)` закомментированы. Python игнорирует их, поэтому попытка изменить элемент кортежа фактически не выполняется.
- Повторное присваивание `menu = (...)` создаёт новый кортеж и связывает имя `menu` уже с ним. Это не изменение старого кортежа по индексу, а замена значения переменной целиком.
- Во втором цикле `for` перебирается уже новый кортеж, поэтому выводится обновлённое меню.

## Проверка

**Основная работа с кортежем выполнена:** программа создаёт кортеж, выводит его элементы, затем присваивает переменной новый кортеж и выводит его содержимое.

**Что не продемонстрировано:** попытка изменить элемент кортежа закомментирована. Поэтому программа не показывает ошибку, которая возникла бы при выполнении такой операции.
