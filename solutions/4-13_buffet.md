# 4-13 — Шведский стол

## Условие

Меню «шведского стола» в ресторане состоит всего из пяти пунктов. Придумать пять простых блюд и сохранить их в кортеже.

- Использовать цикл `for` для вывода всех блюд.
- Попробовать изменить один из элементов и убедиться, что Python отказывается вносить изменения.
- Заменить два пункта меню другими блюдами, присвоив переменной новый кортеж, и вывести обновлённое меню циклом `for`.

## Исходный код

```python
menu = ("nasvay", "solunka", "neskwik", "pivo", "pizza")

print("вот меню сук")
for menus in menu:
    print(menus)

#menu[0] = 250
#print(menu)

menu = ("jaime", "solunka", "neskwik", "onion", "pizza")
print("вот меню сук")
for menus in menu:
    print(menus)
```

## Объяснение

- `menu = (...)` создаёт кортеж из пяти элементов. Кортеж похож на список, но его элементы нельзя изменять по отдельности.
- Первый `print()` выводит заголовок перед списком блюд.
- Цикл `for menus in menu` перебирает кортеж: на каждой итерации переменная `menus` получает очередной элемент.
- `print(menus)` выводит текущий элемент кортежа.
- Строки `#menu[0] = 250` и `#print(menu)` закомментированы. Python игнорирует их, поэтому попытка изменить элемент кортежа фактически не выполняется.
- Если выполнить присваивание `menu[0] = 250`, Python выдаст `TypeError`: элементы кортежа нельзя менять.
- Повторное присваивание `menu = (...)` создаёт новый кортеж и связывает имя `menu` уже с ним. Это не изменение старого кортежа по индексу, а замена значения переменной целиком.
- Во втором цикле `for` перебирается уже новый кортеж, поэтому выводится обновлённое меню.

## Проверка

**Основная логика упражнения выполнена:** программа создаёт кортеж из пяти пунктов, выводит его, затем присваивает переменной новый кортеж и выводит обновлённое меню.

**Нюанс:** попытка изменения элемента оставлена в комментарии. Пользователь объяснил принцип правильно: элемент кортежа изменить нельзя, но переменной можно присвоить другой кортеж. Чтобы буквально увидеть ошибку Python, закомментированную строку можно временно раскомментировать и запустить отдельно.
