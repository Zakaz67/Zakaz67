## Мой код

```python
names = ["parya", "pdidi", "pachik"]
print(names[0])
print(names[1])
print(names[2])
```

## Объяснение кода

1. `names = [...]` создаёт список из трёх строк.
2. `names[0]` обращается к первому элементу списка.
3. `names[1]` обращается ко второму элементу.
4. `names[2]` обращается к третьему элементу.
5. Каждый вызов `print()` выводит один элемент отдельно.

В Python индексация списка начинается с нуля, поэтому первый элемент имеет индекс `0`.

## Статус

Задание выполнено. Каждый элемент выведен отдельно через обращение по индексу.
