# Zakaz67 — самостоятельное изучение Python

Личный архив обучения по книге Эрика Мэтиза **«Изучаем Python»** (*Python Crash Course*).

Здесь хранятся упражнения, объяснения кода, конспекты глав, заметки и идеи будущих проектов. Главная цель — научиться самостоятельно разбираться в задачах и писать программы.

## Структура

- **[solutions/](solutions/)** — объяснения решений и разборы кода.
- **[tasks/](tasks/)** — условия задач из книги.
- **[thoughts/](thoughts/)** — личные записи и выводы после занятий.
- **[code_explanations/](code_explanations/)** — решения упражнений.
- **[notes/](notes/)** — конспекты глав и заметки по обучению.
- **[ideas/](ideas/)** — идеи будущих проектов.

## Текущий прогресс

- **Книга:** «Изучаем Python» — Эрик Мэтиз.
- **Глава:** 5 — условные конструкции, в процессе завершения.
- **Последние проверенные упражнения:** 5-8, 5-9 и 5-11.
- **Ближайшая задача:** завершить 5-10 и проверить оформление по 5-12.

Конспект главы 5: [notes/chapter_5.md](notes/chapter_5.md).
